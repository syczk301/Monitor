# 4.9.7 网络地址自动适配

电脑端与手机端均升级至 4.9.7。先使用任意一个可用地址连通电脑，手机会从 HTTPS 健康检查中学习该电脑在 ZeroTier 和 Tailscale 下的对应地址。

设置页切换网络后，会立即带入该网络的地址及其独立认证信息；点击保存后切换实际连接。ZeroTier 使用该网络当前的虚拟 IP 和服务端口，Tailscale 优先使用稳定的 `.ts.net` HTTPS 域名和 443 端口，不沿用 ZeroTier 的 IP 或端口。

## 同步与手动覆盖

- 服务端直接读取 Windows 的活动虚拟网卡与 ZeroTier 网络 ID，Tailscale 名称通过该虚拟 IP 的反向 DNS 查询取得，并检查本机 443 端口可用。不启动 PowerShell、Tailscale CLI 或其他辅助进程。
- 电脑端缓存约 30 秒，手机在连接成功、启动及后续健康检查时更新地址。只有从正在连接的 HTTPS 服务器取得的提示才参与适配。
- ZeroTier 地址只应用于用户选择的对应网络 ID；不会自动加入其他网络。
- 两种网络的用户名和密码分别保存，自动同步不会复制认证信息。
- 已确认属于同一服务器的地址可自动刷新。旧配置把相同服务器 IP 复制到两种模式时会得到纠正；属于其他电脑的已保存配置不被覆盖。
- 关闭“自动适配服务器地址”后使用手动地址。后台同步不会抹掉正在编辑但未保存的内容，也不会因另一套地址更新而重启当前视频连接。
- 旧电脑端仍可使用各网络已保存的地址；自动发现需要电脑端 4.9.7。

## Tailscale 首次登录

选中 Tailscale 后可直接点击“启动 Tailscale 登录”，无需先填写服务器地址。浏览器授权后返回应用，再选择自动同步的地址或填写地址。尚未连接过任何电脑时，需要先填写一个可用地址；本功能不会扫描或猜测任意服务器。

## 验证

测试覆盖不同地址和端口的选择、同一服务器 ZeroTier IP 变化、旧配置误用同一 IP、持久化、手动覆盖、其他电脑保护、后台同步保留未保存输入，以及拒绝外部网络 ID 和不合法 URL。

Android 仪器测试使用只读 Windows 元数据测试服务，读取本机真实虚拟网卡产生的 HTTPS 响应并验证两套地址的保存与选择；不启动额外摄像头，不中断正在运行的录像。另验证无服务器地址时启动内置 Tailscale 登录。

发布前使用 `testDebugUnitTest`、`assembleRelease`、`lintVitalRelease`、相关 Windows Rust 测试和 Android 仪器测试验证。全工作区 Rust 测试曾被系统拒绝执行未修改的存储测试 EXE，相关的 app/media/web 测试单独执行通过；这不是存储测试断言失败。
