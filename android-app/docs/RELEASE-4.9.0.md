# 手机版 V4.9.0

- 内置 ZeroTier SDK，应用启动时自动连接配置的网络，无需先打开独立 ZeroTier 应用。
- 设置页增加网络开关、网络 ID、节点 ID 和连接状态。内置节点使用独立身份，首次安装后需在 ZeroTier 后台授权手机显示的新节点 ID。
- 增加启动检查更新、手动检查、下载进度、SHA-256 校验和系统安装入口。更新包须匹配应用包名和签名，禁止降级。
- 兼容 Android 8.0 及以上，提供 ARM64、ARMv7、x86_64 支持，可覆盖安装同签名旧版。

验证：发布构建、Lint Vital、6 项单元测试、模拟器 SDK 初始化与节点身份持久化、V4.7.1 覆盖安装均通过。

当前模拟器未完成 ZeroTier 根服务器连接，GitHub 更新检查返回 connection closed。实际手机上的节点授权、监控画面、音频、录像访问及真实更新下载安装仍需验证。

下载 `monitor-V4.9.0-release.apk` 安装；同名 `.sha256` 文件用于校验。本发布仅提供 Android 安装包，Windows 最新正式版保持 v4.8.4。
