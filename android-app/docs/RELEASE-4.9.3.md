# 手机版 V4.9.3

修复冷启动时 ZeroTier 尚未就绪，监控请求提前进入内置 CONNECT 转发层而显示 `Unexpected response code for CONNECT: 502` 的问题。

- API 在网络配置完成后才对页面公开，并通过 Compose 状态触发刷新。
- API、视频和音频共享的连接入口等待内置网络就绪，最长 30 秒；等待期间取消请求会及时退出。
- 未就绪时显示当前网络状态；就绪后 CONNECT 失败显示服务器地址、端口与检查提示，保留底层异常供诊断。
- HTTPS 证书验证和服务器访问范围限制保持原有行为。

验证：回归覆盖启动等待期间不打开连接、就绪后发送请求、等待超时的网络状态提示、取消等待，以及真实 OkHttp CONNECT 502 的错误提示转换。发布构建及 Lint Vital 通过。

这是本地签名修复包，尚未发布 GitHub。该修复处理已确认的启动时序问题；手机网络就绪后的持续连接超时仍需要实际服务器地址与手机运行结果来定位。
