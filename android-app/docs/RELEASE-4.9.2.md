# 手机版 V4.9.2

按用户选定的设置页面方案 1 重新布局。

- 服务器连接、网络连接、软件更新分组展示；服务器地址优先显示。
- 访问认证、网络 ID / 节点与连接帮助、更新说明按需展开。
- 保存按钮固定在底部；键盘弹出时隐藏设置页底部导航，保存按钮保持可见。
- 去除重复标题和重复连接成功提示，增加待保存状态与节点 ID 复制按钮。
- 保留内置 ZeroTier、FlClash 共存、服务器认证与更新下载安装功能。

发布构建和 Lint Vital 通过，已验证旧版覆盖安装、真实保存与 HTTPS 健康检查、折叠交互、密码显示切换、节点复制、软键盘、小屏幕和 1.3 倍字体布局。实际对照记录见 `android-app/design-qa.md`。
