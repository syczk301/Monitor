# 4.8.1：托盘与更新窗口

- 托盘菜单按监控、录像和维护分组，显示版本与实时录像状态，支持键盘快捷键；默认项为打开监控面板。
- 每次打开托盘菜单时读取当前用户的 CameraMonitor 开机启动项，显示已开启、未开启、被系统禁用、指向其他版本或状态未知；只读显示，不修改启动设置。
- 运行状态读取实际摄像头、分辨率、帧率、录像文件和异常信息，替代固定说明。
- 检查更新改为统一窗口，包含版本对比、可滚动和复制的更新说明、下载进度、重试和完成状态。
- 检查和下载可取消；安装时禁止关闭；更新窗口打开期间禁用重复检查菜单项。
- 更新说明按 UTF-8 解码，避免 Windows PowerShell 5.1 下中文乱码。
- 本地版本高于在线稳定版时明确提示，无需降级。

验证：Windows PowerShell 5.1 下 16 项界面检查、29 项更新校验、真实测试进程替换及启动失败回滚通过。检查窗口状态渲染，并在本机 4.8.1 上验证原生菜单、托盘唤起更新窗口和匿名在线检查；本机替换后配置哈希不变、定时录像恢复，健康接口正常。

构建产物位于 `dist/release-v4.8.1`，包含客户端、SHA-256 校验文件和 x64 安装包。正式更新源为 [GitHub Release v4.8.1](https://github.com/syczk301/Monitor/releases/tag/v4.8.1)。4.8.0 客户端通过托盘“检查更新”获取此版本；4.7 客户端需先退出旧版并手动安装。
