# 4.8.4：右键菜单控制开机启动

托盘右键菜单新增可勾选的“开机启动”项，可直接开启或关闭当前版本的开机启动。

- 勾选后，将启动项注册到当前客户端路径；用户主动开启时，也会解除 Windows 启动设置中的禁用状态。
- 取消勾选后，删除当前用户的 CameraMonitor 启动项。
- 每次打开菜单重新读取实际启动状态，勾选状态随设置变化。
- 保留启动项指向其他版本、被系统禁用或状态未知的提示，以及启动路径修复功能。

验证：原生菜单勾选与可点击状态、真实 Windows 注册表启用/禁用、系统禁用后重新开启、路径修复和扩展路径处理测试通过。本机客户端更新后摄像头运行正常。实际重启登录后的自启尚未验证。

发布文件：`CameraMonitor.exe`、`CameraMonitor.exe.sha256`、`CameraMonitor-4.8.4-x64.msi`。现有 4.8.x 客户端可通过托盘“检查更新”升级。
